# Spark! — Sense · Think · Move

A static website (no build step, no dependencies).

- `index.html` — the 23-slide animated deck (← → keys, swipe, M = menu, F = fullscreen)
- `quiz.html` — Typeform-style 15-question quiz (edit questions at the top of `quiz.js`)
- `style.css`, `quiz.css`, `app.js`, `quiz.js`

## Deploy
Drag this folder onto Netlify Drop / Vercel / Cloudflare Pages, or push to GitHub and enable GitHub Pages.
Share `…/quiz.html` with students; present from `…/index.html`.
Open locally by double-clicking index.html.
